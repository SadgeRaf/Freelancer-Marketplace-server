# Freelancer Marketplace (Server)

A Node.js and Express backend API powering the Freelance Marketplace platform. Handles authentication, job creation, updates, deletion, and retrieval. MongoDB and Mongoose provide secure data storage, and Firebase Admin ensures secure authentication.

---

## 🚀 Tech Stack
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB, Mongoose  
- **Authentication:** Firebase Admin  
- **API:** RESTful endpoints  

---

## ✨ Main Features
- Secure authentication and authorization  
- Full CRUD operations for jobs/tasks  
- Modular architecture for scalability  
- CORS enabled and production-ready endpoints  

---

## 🧩 Dependencies
- express  
- cors  
- mongoose  
- dotenv  
- firebase-admin  
- nodemon  

---

## 💻 Local Setup
1. Clone the repository:  
```bash
git clone https://github.com/SadgeRaf/Freelancer-Marketplace-server.git
Install dependencies:

npm install


Set up .env with database and Firebase credentials

Start the server:

npm run dev


The API runs on http://localhost:3000 by default
